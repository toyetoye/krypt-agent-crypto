# Krypt Agent Crypto

Krypt Agent Crypto is a systematic paper-trading and research engine for crypto market-neutral and hybrid strategies.

The initial focus is on:
- Funding-rate collection
- Spot/perpetual basis arbitrage
- Mean-reversion strategies
- Momentum/regime classification
